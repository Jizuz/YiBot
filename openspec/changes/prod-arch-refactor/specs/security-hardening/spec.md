# 规格：安全止血（security-hardening）

## 能力概述

消除系统存量高危安全问题：泄漏密钥出库、数学表达式安全求值、密码明文存储迁移、敏感产物移出版本库，使系统达到医疗问诊业务上线的安全基线。面向用户、开发与安全审计角色。

## 业务前置条件

- 高德开放平台已完成新 Key 申请与旧 Key 作废（**先轮换、后改码**，运维前置）；
- 数学计算工具仅服务于问诊中的简单算术诉求（如用药剂量换算提示）；
- 存量用户表并存 `password`（明文）与 `hash_pwd`（哈希，历史上闲置）两列；
- 版本库当前追踪了本地向量库二进制产物目录。

## 输入定义

| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 天气/位置查询请求 | 工具调用 | 是 | 城市名等参数，经高德开放接口查询 |
| 数学表达式 | 工具调用 | 是 | 用户侧算术诉求，字符串形式 |
| 登录凭据（手机号+密码） | 登录请求 | 是 | 触发存量明文密码惰性升级 |
| 密钥配置 | 部署配置 | 是 | 轮换后的高德 Key，经配置注入，禁止硬编码 |

## 输出定义

| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 天气查询结果 | 业务数据 | 与改造前一致，行为不变 |
| 数学计算结果 | 业务数据 | 仅允许算术运算结果；非法/注入输入被拒绝 |
| 密码存储变更 | 数据状态 | 新注册/升级后仅存不可逆哈希，明文列清空 |
| 版本库状态 | 仓库状态 | 无有效密钥、无向量库二进制产物被追踪 |

## 主流程（正向链路）

1. 用户触发天气查询：工具使用配置注入的新 Key 调用开放接口，正常返回结果；
2. 用户触发数学计算：表达式经受限解析求值（仅算术，无代码执行能力），返回计算结果；
3. 新用户注册：密码仅以不可逆哈希落库，明文列置空；
4. 存量用户首次登录：明文匹配通过后自动升级为哈希存储并清空明文，登录成功且后续登录走哈希校验；
5. 版本库清理：向量库产物移出追踪（本地文件保留），泄漏 Key 相关代码改为配置读取。

## 分支场景

- 存量用户已升级过哈希：直接哈希校验，跳过升级逻辑；
- 用户同时命中"明文密码正确"与"哈希已存在"：以哈希校验为准，不覆盖已有哈希；
- 调试/脚本场景引用计算工具：与线上行为一致，无特权通道。

## 异常场景 & 业务错误码

| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 数学表达式含非算术内容/危险语法 | 参数错误（4xx 业务码） | 返回"仅支持四则运算等算术表达式"类提示，不执行任何求值 |
| 表达式语法非法（括号不匹配等） | 参数错误（4xx 业务码） | 返回格式错误提示 |
| 旧 Key 残留调用 | 上游拒绝 | 天气工具返回上游失败，不暴露 Key 信息 |
| 存量明文密码与输入不匹配 | 凭据错误（401 业务码） | 登录失败，不触发升级（与鉴权能力错误口径一致） |

## 数据约束

- 密码升级为幂等操作：重复登录不重复迁移、哈希仅覆盖一次；
- 明文列清空不可逆，升级成功后任何路径不得再写明文；
- 哈希算法不可逆且带随机盐，同密码两次哈希结果不同（不可作为相等性比较依据）；
- 清尾扫描只读告警，不自动改数。

## 权限与数据隔离

- 密码迁移仅由用户本人登录触发，不存在批量明文回读接口；
- 清尾告警仅输出账号数量/清单给管理侧，不输出明文内容。

## 并发与重试规则

- 同一账号并发登录触发升级：以先完成者为准，后到者按哈希校验，不允许写坏；
- 天气/计算工具按上游语义可重试，重复调用无副作用。

## 业务容量约束

- 数学表达式长度与运算规模受限（超长拒绝），防止资源滥用；
- 清尾扫描为低频定时任务，避开业务高峰。

## 验收用例（测试要点）

✅ 正向用例
- 新用户注册 → 库中仅哈希、明文列为空；
- 存量明文用户首次登录成功 → 明文列清空、哈希列有值；二次登录仍成功（走哈希）；
- 天气查询返回与改造前一致；
- 正常算术表达式（加减乘除、括号、小数）计算正确。

🔄 边界用例
- 已升级用户重复登录不产生二次迁移；
- 大数/精度边界表达式结果符合算术语义；
- 向量库目录本地仍在、版本库不再追踪。

❌ 异常用例
- 注入样例（`__import__`、函数调用、分号拼接、`e` 幂记号等）一律拒绝，无代码执行；
- 错误密码登录不触发迁移；
- 仓库历史复查：搜索旧 Key 无有效命中（旧 Key 已在开放平台作废）。

## 兼容与灰度规则

- 密码迁移不停机：明文/哈希双读窗口，直至清尾扫描无明文残留；
- 天气、计算工具对外行为不变，仅内部实现与密钥来源变化，调用方零感知；
- 向量库出库不影响本地开发与已部署环境。

## 业务埋点与告警指标

- 清尾扫描：仍存在明文密码的账号数（>0 告警）；
- 数学表达式拒绝次数突增（疑似攻击探测）；
- 天气工具上游失败率。

## 规格备注

- 与 `access-auth` 强关联：登录升级入口、凭据错误口径由该能力定义；
- 密钥轮换是运维前置动作，代码出库必须晚于旧 Key 作废；
- 明文列最终删除（表结构变更）属于 `production-hardening` 的迁移工具范畴。
