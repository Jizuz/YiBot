# 规格：接入鉴权（access-auth）

## 能力概述

为医疗问诊系统提供前后端全链路的登录鉴权能力：手机号+密码登录（登录即注册）、访问/续期双令牌颁发与轮换、登出吊销、受保护接口身份一律从令牌获取，杜绝 user_id 明文冒充。面向患者用户（前端 Chatte）与管理/调试方（curl 等）。

## 业务前置条件

- 用户持有 11 位手机号与密码（密码最短 4 位，沿用现状）；
- 受保护接口范围：问诊对话、会话列表/历史/关闭、消息保存、当日配额查询等业务接口；
- 存量数据：会话检查点以 `user-{uid}-{sid}` 标识绑定历史会话，标识格式不可变更；
- 安全止血能力已就绪（密码哈希存储与惰性升级，见 `security-hardening`）。

## 输入定义

| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| mobile | 登录请求 | 是 | 11 位手机号 |
| password | 登录请求 | 是 | 明文密码，仅在登录/续期请求中传输 |
| Authorization 请求头 | 受保护接口 | 是 | `Bearer {访问令牌}`，替代原 user_id query 传参 |
| 续期令牌 | 续期请求 | 是 | 登录时一并颁发的长时效令牌 |

## 输出定义

| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 访问令牌（access） | 凭据 | 短时效（默认 30 分钟），日常请求携带 |
| 续期令牌（refresh） | 凭据 | 长时效（默认 7 天），仅用于换取新令牌，轮换式使用 |
| 用户信息 | 业务数据 | 含 uid/昵称等，**任何响应不含密码字段** |
| 会话保持状态 | 前端状态 | 刷新页面/重开浏览器（7 天内）无需重新输密码 |

## 主流程（正向链路）

1. 用户在前端输入手机号+密码登录：系统校验凭据（不存在则自动注册并登录，即"登录即注册"），颁发访问令牌与续期令牌，返回用户信息（无密码）；
2. 前端保存登录态（访问令牌驻内存、续期令牌持久化，刷新页面静默恢复）；
3. 用户发起问诊/会话/配额等请求：前端自动附带访问令牌，系统从令牌解析身份（uid），据此关联其会话、权益与配额；
4. 访问令牌到期：请求返回 401，前端自动用续期令牌换取新令牌对并**重放原请求**，用户无感知；
5. 用户登出：前端调用登出接口，服务端吊销该用户全部令牌，前端清理本地登录态（含历史遗留的明文密码旧键）。

## 分支场景

- 登录即注册：手机号不存在时直接创建账号并登录，注册与登录为同一动作；
- 存量明文密码用户首次登录：校验通过后自动升级哈希（见 `security-hardening`），登录正常完成；
- 刷新页面/重开浏览器：访问令牌虽驻内存已丢失，凭持久化的续期令牌静默恢复会话；
- 多标签页并发触发续期：仅一次续期生效，其余复用结果，不产生令牌互废；
- 过渡期兼容：前端未携带令牌但 query 携带 user_id 的旧请求，服务端放行并记录告警日志（回退通道，保留一个发布周期后下线）。

## 异常场景 & 业务错误码

| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 未携带令牌访问受保护接口（非过渡期兼容场景） | 401 | 返回未登录，前端跳转登录页 |
| 访问令牌过期 | 401 | 前端静默续期并重放请求；续期失败才提示重新登录 |
| 令牌被篡改/签名无效/类型不符 | 401 | 直接拒绝，不进入续期流程 |
| 访问令牌已登出吊销 | 401 | 拒绝（登出后旧令牌即刻不可用） |
| 续期令牌过期/已轮换/已吊销 | 401 | 续期失败，清理本地状态并引导重新登录 |
| 密码错误 | 401 业务码 | 提示"手机号或密码错误"，不区分账号不存在（防撞库探测） |
| 手机号格式非法/密码过短 | 4xx 业务码 | 前端本地拦截为主，服务端兜底校验 |

## 数据约束

- 身份标识 uid 的类型转换规则（纯数字转数值）与会话标识 `user-{uid}-{sid}` 格式**必须与存量检查点数据完全一致**，否则历史会话丢失；
- 续期令牌采用白名单制：仅白名单内的续期令牌可换新；轮换即旧续期令牌作废；
- 登出吊销对访问令牌即刻生效（黑名单语义）；
- 同一账号可多端登录，各端令牌独立（吊销范围：登出请求所在端的令牌对）。

## 权限与数据隔离

- 用户只能访问自己的会话、消息、权益与配额：身份以令牌为准，**query/body 中携带的任何 user_id 一律忽略**（伪造无效）；
- 用户信息查询接口不再返回密码字段（含脱敏后的存量接口，处置见规格备注）；
- 令牌中的身份不可被客户端修改（签名保护）。

## 并发与重试规则

- 续期操作幂等防重：并发 401 触发多次续期时仅一次生效；
- 登录接口允许失败重试，但受网关按 IP 频控保护（见 `gateway-traffic-governance`）；
- 前端请求重放仅针对"令牌过期续期"场景，业务失败不自动重放。

## 业务容量约束

- 访问令牌默认有效期 30 分钟、续期令牌 7 天（可配置）；
- 登录/续期接口按 IP 限频（默认 20 次/分钟），超出拒绝（防爆破）。

## 验收用例（测试要点）

✅ 正向用例
- curl 全链路：登录 → 带令牌访问问诊接口 → 令牌过期 401 → 续期成功 → 新令牌可用；
- 前端 Chatte：登录走新登录接口，响应与本地存储均无密码字段；
- 前端所有业务请求携带 Authorization 头且不再出现 user_id 参数（DevTools 验证）；
- 访问令牌过期后前端自动续期并重放，对话不被打断；
- 刷新页面后登录态保持，无需重新登录。

🔄 边界用例
- 登录即注册：新手机号首次登录直接可用，历史会话为空属正常；
- 存量明文密码用户首次登录成功且自动升级；
- 双开标签页同时过期：续期一次成功，两标签页均可用；
- 过渡期旧客户端 query 传 user_id 可用但产生告警日志。

❌ 异常用例
- 无令牌访问受保护接口 → 401；
- 篡改令牌 payload（改 uid）→ 401，且无权访问他人会话；
- 改 query 中 user_id 冒充他人 → 无效（身份仅取自令牌）；
- 登出后旧访问令牌、旧续期令牌均不可用；
- 旧续期令牌二次使用（已轮换）→ 拒绝。

## 兼容与灰度规则

- 过渡期（默认一个发布周期）：无令牌 + query user_id 的旧请求放行并告警，作为前端切换回退通道；到期后彻底拒绝；
- 前端本地历史遗留登录键（可能含明文密码）在新版本首次启动时清理替换，不残留；
- 存量用户信息查询接口在过渡期内停止返回密码字段（脱敏），前端切换验收后按"下线"处置（见备注）；
- 鉴权能力提供配置开关，异常情况下可紧急降级放行（止血用，需告警）。

## 业务埋点与告警指标

- 401 拒绝率与续期成功率（续期失败突增 → 前端异常或令牌服务异常）；
- 过渡期兼容告警量（归零作为下线前置条件）；
- 登录失败次数按 IP 聚合（撞库探测信号，联动网关频控）。

## 规格备注

- 强关联：`security-hardening`（密码哈希与升级）、`gateway-traffic-governance`（登录频控）、`llm-token-quota`（配额查询接口复用本能力鉴权）；
- 旧接口 `/user/detail/mobile`、`/user/add` 随伪登录链路下线：过渡期脱敏保留，前端切换验收后移除（对应提案"下线能力 legacy-plain-auth"）；
- 令牌校验位于应用侧（已定架构决策，网关专注流量治理），多服务复用时用户体系收敛在应用侧。
