# 规格：网关流量治理（gateway-traffic-governance）

## 能力概述

在系统唯一入口处提供流量治理能力：分层限流（并发/速率/次数）、后端异常熔断与半开恢复、CORS 统一收敛、后端端口收敛，保护长耗时 LLM 问诊链路不被流量打垮。面向全体外部调用方（前端、管理方、压测工具）。

## 业务前置条件

- 网关作为唯一对外入口部署，后端服务端口不再直接暴露；
- 已定架构决策：令牌校验在应用层，网关不做用户身份校验，仅做流量治理与 CORS；
- 限流维度以来源 IP 为主（未登录接口）与业务维度（登录后接口）相结合。

## 输入定义

| 名称 | 类型 | 是否必填 | 说明 |
| ---- | ---- | -------- | ---- |
| 外部请求 | HTTP 流量 | 是 | 前端/管理方/工具发起，经网关进入 |
| 来源标识 | 请求属性 | 是 | 来源 IP（登录类接口频控维度） |
| 后端健康信号 | 系统状态 | 是 | 后端响应成功/失败，驱动熔断状态机 |

## 输出定义

| 名称 | 类型 | 说明 |
| ---- | ---- | ---- |
| 正常响应 | 业务响应 | 限流/熔断未触发时透传后端结果 |
| 限流响应 | 429 | 超出并发/速率/次数阈值时拒绝，附友好提示 |
| 熔断响应 | 503 | 后端持续异常时快速失败，不再透传等待 |
| CORS 响应头 | 响应头 | 统一由网关下发，收敛来源白名单 |

## 主流程（正向链路）

1. 请求到达网关：按路由匹配限流策略（并发/速率/次数）；
2. 未超阈值：转发后端，透传响应；跨域请求由网关统一应答 CORS 头；
3. 后端持续返回异常（如连续 5xx 达阈值）：对应路由进入熔断，后续请求快速失败；
4. 熔断冷却期满：进入半开状态，放行少量探测请求；成功则恢复，失败则继续熔断。

## 分支场景

- 登录/续期接口：按 IP 次数限流（默认 20 次/分钟，计数跨网关实例共享），防撞库爆破；
- 问诊对话接口：长耗时 LLM 调用以并发上限为主、速率为辅，避免长请求占满速率配额导致误杀；
- 管理类接口（知识库等）：从严限速；
- 熔断半开恢复：探测流量仅少量放行，成功后逐步恢复全量。

## 异常场景 & 业务错误码

| 场景 | 错误码 | 业务表现 |
| ---- | ------ | -------- |
| 问诊接口并发超上限（默认 50） | 429 | 提示"当前咨询人数较多，请稍后再试" |
| 问诊接口速率超限（默认 2/秒、突发 5） | 429 | 同上友好提示 |
| 普通业务接口速率超限（默认 10/秒） | 429 | 通用限流提示 |
| 登录类接口超频（默认 20 次/分/IP） | 429 | 提示"操作过于频繁，请稍后再试" |
| 熔断开启期间请求 | 503 | 快速失败提示"服务暂时不可用" |
| 后端不可达/超时 | 503/504 | 熔断计数累积，触发状态机 |

## 数据约束

- 登录类限流计数必须跨网关实例一致（共享存储语义），避免多实例下限流被稀释；
- 限流/熔断阈值全部可配置，不硬编码；
- 熔断状态机：关闭 → 打开（连续失败达阈值）→ 半开（冷却期满）→ 恢复/再打开，状态迁移单向明确。

## 权限与数据隔离

- 网关不解析业务身份，不做数据隔离（由应用层鉴权负责）；
- CORS 白名单收敛至网关统一管理，后端不再各自放行。

## 并发与重试规则

- 被限流/熔断拒绝的请求由调用方退避重试，网关不排队放行；
- 熔断半开探测请求与正常请求同等计费限流，不产生旁路。

## 业务容量约束

| 路由类别 | 默认阈值 | 说明 |
| ---- | ---- | ---- |
| 问诊对话 | 并发 50；速率 2/秒、突发 5 | 长耗时 LLM 为主 |
| 其他对话/会话类 | 速率 10/秒 | 普通查询类 |
| 登录/续期 | 20 次/分/IP | 防爆破 |
| 知识库管理类 | 速率 5/秒 | 从严 |
| 熔断 | 连续异常 ≥3 次打开、冷却 10 秒 | 半开探测恢复 |

## 验收用例（测试要点）

✅ 正向用例
- 正常流量全链路透传，业务行为与直连后端一致；
- 跨域请求由网关返回正确 CORS 头，白名单外来源被拒。

🔄 边界用例
- 压测问诊接口至并发 50：第 51 个并发请求被限流（429）；
- 登录接口同 IP 每分钟第 21 次请求被拒；
- 后端恢复后半开探测成功，服务自动恢复全量。

❌ 异常用例
- 停后端：熔断开启，请求快速失败（503）不再长时间挂起；
- 熔断期间恢复后端：冷却期满后半开探测 → 恢复；
- 后端端口从外部直连：不可达（仅网关入口暴露）。

## 兼容与灰度规则

- 网关可整体摘除回滚：调用方切回直连后端即可恢复业务（回滚预案）；
- 上线顺序：网关与后端并存验证 → 前端入口切换至网关 → 关闭后端直连暴露；
- 为长连接流式响应预留参数（读超时、禁用响应缓冲），本期不交付后端流式化，仅保证不阻塞后续启用。

## 业务埋点与告警指标

- 各路由限流触发次数（突增 → 异常流量或容量不足）；
- 熔断状态迁移事件（打开/半开/恢复均告警）；
- 网关 5xx 比例、后端响应时长分布。

## 规格备注

- 与 `access-auth` 协作：登录类频控保护鉴权接口；网关不做身份校验（已定决策）；
- 与 `llm-token-quota` 互补：网关拦"请求量"，配额拦"用量"，两层独立生效；
- 阈值默认值来自技改方案，容量调优属后续迭代（本次仅验证功能正确性）。
